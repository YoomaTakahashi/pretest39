# pretest39

--ระบบประเมินบุคลากรวิทยาลัยเทคนิคน่าน--

|   การสมัครสมาชิกเพื่อเข้าสู่ระบบ    |

    -ฝ่ายบุคลากร (ไม่สามารถสมัครสมาชิกโดยตรงได้)
    -ผู้รับการประเมิน
    -กรรมการประเมิน

|   การเข้าสู่ระบบ     |
    -ฝ่ายบุคลากร ถ้าเข้าสู่ระบบสำเร็จจะเข้าไปที่หน้าแสดงภาพรวมของระบบประเมินบุคลากร
    -ผู้รับการประเมินผล (จะตรวจสอบการเข้าสู่ระบบครั้งแรก ถ้าเข้าสู่ระบบครั้งแรกจะเข้าไปที่หน้าเปลี่ยนรหัสผ่านครั้งแรก)
    แต่ถ้าไม่ได้เข้าสู่ระบบครั้งแรกจะเข้าไปที่หน้าแสดงภาพรวมของผู้รับการประเมินผล
    -กรรมการประเมิน ถ้าเข้าสู่ระบบสำเร็จจะเข้าไปที่หน้าแสดงรายชื่อผู้รับการประเมิน

| ระบบการทำงานแต่ละฝ่าย |
    -ฝ่ายบุคลากร
        แสดงภาพรวมของระบบประเมินบุคลากร จัดการผู้ใช้ หัวข้อการประเมิน,ตัวชี้วัด,รอบการประเมิน,แบบประเมิน และรายงานผู้รับการประเมินพร้อมพิมพ์เอกสาร
        
    -ผู้รับการประเมินผล
        แสดงสถิติเชิงร้อยละ ประเมินตนเอง และแนบหลักฐาน

    -กรรมการประเมิน
        ให้คะแนนและข้อเสนอแนะแก่ผู้รับการประเมิน

|   สถานะการอนุมัติ    |
    ฝ่ายบุคลากรจะต้องเพิ่มหัวข้อการประเมิน ตัวชี้วัด รอบการประเมิน แบบประเมิน และจับคู่กรรมการเพื่อให้ผู้รับการประเมินประเมินตนเอง
    ผู้รับการประเมินจะต้องประเมินตนเองและแนบหลักฐานการประเมินพร้อมให้กรรมการดำเนินการประเมินต่อ
    กรรมการประเมินจะต้องประเมินผู้รับการประเมินและทำการแนบลายเซ็นให้ครบ 3ท่านเพื่อเป็นการอนุมัติการประเมิน
    เมื่อกรรมการ 3 ท่านทำการแนบลายเซ็นต์แล้วจะทำการอนุมัติการประเมิน
